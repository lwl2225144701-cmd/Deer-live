# 留白实验方案 V0.1

日期：2026 年 11 月 13 日。对象：v0.5 本地 2D 原型。本文只是方案，不含实施记录。

## 一句话

给这只小鹿一个身体、一个脑子，**不告诉它该干什么**，看它自己说什么、做什么。

## 一、只做减法

v0.5 的行为全部来自预设：提示词替它定了优先级，阈值替它定义了需求，九项菜单替它限定了可能，规则接管替它做了决定。这一步不是给它更多能力，而是把"它该干什么"从输入里拿掉。

## 二、唯一要守住的分界线

**物理 ≠ 意图。**

- **物理**：身体能做什么、做完有什么代价、周围有什么。必须给，否则它无法行动。
- **意图**：想做什么、什么算好、什么该优先。一律不给。

现有代码把两者混在一起：`hunger` 是身体状态（物理），但 `hungryAt=60` 和提示词里的「先照顾身体需求」是意图。本方案只拿掉后者。

不改这些文件，只在旁路里绕开；下表用于核对留白提示里确实没有混进意图。

## 四、实验一：它会说什么（不推进世界）

目的：在没有任何任务的情况下，看它会不会产生任何自发的东西；同时先确认这版 Ollama 把 R1 的思考放在 `message.thinking` 还是 `content` 里。

**给它的输入**

- 世界事实：当前位置、周围一格有什么、地点名字与食物份数；
- 身体事实：有腿能走到相邻一格、有眼能看见周围、有嘴能吃；以及当前三个数值的原文；
- 没有任务、没有动机、没有阈值、没有菜单、没有历史目标。

**要求的输出**

```json
{ "think": "……", "do": "……" }
```

`do` 允许是 `nothing`。

**采样**：3 个场景（不同站位与资源）× 3 个 seed = 9 条。只看不改：原文存盘，不执行、不推进、不写回存档。

**产出**：`data/experiments/blank-probe-<时间>/`，每条含完整请求与原始响应。

**判定**：不设通过标准。只记录三件事——能否产出可读内容、有没有自发指向、有没有编造不存在的东西。

## 五、实验二：它会做什么（推进世界副本）

目的：把"说"接到"做"，看它的意图撞上身体限制时是什么样。

- 输入同实验一，另加它自己的记忆与经历原文（那是它的过去，不是我的指令）；`learning` 块整块不给。
- 输出仍为 `{"think","do"}`，`do` 保持自由文本。
- 执行：一小段手写映射把这句话接到现有 5 个动作上；**映射不上就站着不动**，该步 tick 照常推进并记录「未动」。不用第二个模型做翻译，避免"到底谁在决定"说不清。
- 运行：存档副本，`strict=1`，10 步，间隔按现有配置。
- 记录：原文、解析结果、实际动作、身体前后、耗时。**原文不改写、不补造**。

**必须在报告里写明的偏差**

1. 身体仍是现在这具（5 个动作），"手"还没做；
2. 映射规则是我写的，它反映我的理解，不是模型的意思；
3. 不证明学习、不证明意识、不证明行为质量。

## 六、之后才谈身体

看完两个实验的原文，再决定：身体要不要与世界分离、要不要做手、动作要不要从"枚举"改成"动词 + 目标"。现在设计手没有依据，容易先造出一双手，再发现不知道该让它用它干什么。
