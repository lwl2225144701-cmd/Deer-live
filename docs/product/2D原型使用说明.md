# DeerLive 2D 原型

v0.5 在已有生命循环上增加本机网页界面。卡通小鹿参考用户提供的形象生成，使用透明 PNG；地图与资源用 Canvas 绘制，界面无需第三方前端依赖。

## 启动

从项目根目录执行：

```bash
# 查看之前的新生小鹿存档
DEER_LIVE_DB=data/newborn.sqlite npm run web

# 使用运行配置中的存档（默认 data/deer-live.sqlite）
npm run web
```

打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。`DEER_LIVE_PORT` 可更换端口。首次打开处于暂停状态；已有存档会恢复，没有存档才创建新世界。按 Ctrl+C 停止服务。

## 观察与控制

- 观察者可看到完整地图；提供给模型的视野和记忆仍由原有规则决定。
- “走一步”让本地 Ollama 模型决策一次；“开始生活”连续串行运行，思考结束后才等待下一步。
- “暂停生活”取消尚未提交的推理，已经完成的行动保留。关闭网页本身不会停止连续运行，离开前可点击暂停或停止服务。
- 模型异常时遵循现有严格模式设定。默认规则接管，日记标为“规则接管”；`DEER_LIVE_STRICT=1` 时停止并显示错误。
- 身体状态、口袋食物、坐标、到访记录、当前目标和日记来自真实存档。点击地点查看当前资源与到访次数；足迹和网格可切换。
- 经历面板显示当前检索的最多六处探索事实，面板中的尝试与收获只对这些地点汇总，不代表任意大小地图的全部历史。

## 代码位置

| 位置 | 内容 |
|---|---|
| `src/web/server.ts` | 本机静态资源和状态/控制接口 |
| `src/web/controller.ts` | 暂停、串行运行、取消推理和现有 tick 的衔接 |
| `web/index.html` / `web/style.css` | 页面布局、桌面和手机宽度适配 |
| `web/app.js` | 状态同步、按钮、日记和角色动画 |
| `web/world.js` | 2D 地图投影、资源绘制、地点选择和足迹 |
| `web/assets/deer.png` | 参考用户形象生成的卡通小鹿透明素材 |

UI 是已有行为的可视化，不增加训练或改变世界规则。模型决策仍可能不合理，小鹿的肢体动画是视觉表现，不是模型生成的骨骼动作。

预览截图见 [桌面](../previews/deerlive-2d-desktop.png) 与 [手机宽度](../previews/deerlive-2d-mobile.png)。


## 本次验证

30 项自动化测试通过。独立 Chrome 验证桌面 1440px 和手机 390px 宽度，未发现脚本错误或横向溢出，网格与足迹切换正常。独立存档浏览器单步实测三次均实际调用 DeepSeek-R1 1.5B；两次严格模式下因输出截断而停止，一次默认模式由规则推进副本到第 19 步并在界面明确标注。原小鹿保持第 18 步。这验证的是可视化接入与失败边界，不代表模型行为改善。记录见 [浏览器实测](../evidence/ui/2026-11-06-browser-smoke.json)。
